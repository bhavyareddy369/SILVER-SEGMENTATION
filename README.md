# Liver Image Segmentation using Deep Learning

## Overview
This project focuses on automated liver image segmentation using Deep Learning and Medical Image Processing techniques. The model was developed to identify and segment liver regions from medical scan images, helping improve accuracy and efficiency in medical image analysis.

The project demonstrates preprocessing, segmentation model development, training, evaluation, and visualization workflows for healthcare AI applications.

---

## Features
- Automated liver image segmentation
- Medical image preprocessing
- Deep learning-based segmentation pipeline
- Visualization of segmented outputs
- Training and evaluation workflow
- Healthcare AI application

---

## Tech Stack
- Python
- TensorFlow / Keras
- OpenCV
- NumPy
- Matplotlib
- Google Colab

---

## Dataset
The project uses liver CT scan images from medical imaging datasets for segmentation tasks.

Dataset preprocessing includes:
- Image normalization
- Resizing
- Mask preparation
- Data augmentation

---

## Model Workflow
1. Medical image preprocessing
2. Image normalization and resizing
3. Segmentation model training
4. Prediction and mask generation
5. Evaluation and visualization

---

## Results
- Successfully segmented liver regions from CT scan images
- Generated segmentation masks for medical image analysis
- Built an end-to-end medical image segmentation workflow
